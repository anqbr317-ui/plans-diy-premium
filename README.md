# Plans Bricolage Premium

Site vitrine statique prêt pour GitHub Pages.

## Fichiers

- `index.html` : page principale
- `style.css` : design du site
- `script.js` : menu mobile et formulaire
- `README.md` : instructions

## Mise en ligne sur GitHub

1. Ouvre le dépôt `plans-bricolage-premium`.
2. Clique sur **Add file** puis **Upload files**.
3. Ajoute `index.html`, `style.css`, `script.js` et `README.md`.
4. Clique sur **Commit changes**.
5. Dans **Settings > Pages**, choisis :
   - Source : **Deploy from a branch**
   - Branch : **main**
   - Dossier : **/(root)**
6. Attends quelques minutes.
